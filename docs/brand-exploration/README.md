# Clyvora logo exploration

Historical exploration notes. The user subsequently selected the custom-wordmark
direction; the adopted local identity is documented in [BRAND.md](../BRAND.md).
The unchanged-production statements below describe the earlier concept rounds.

Three original vector studies based on the double-C logo shown on clyvora.tech on 16 November 2026. These are proposals, not an approved identity or a trademark clearance.

- **Cut** — recommended starting point. A single substantial C, with parallel diagonal terminals. The cut is carried through the top and bottom rather than adding a second symbol inside the C.
- **Ribbon** — a softer, more expressive silhouette. Its tapered lower terminal carries the movement; no gradients or shading are needed.
- **Fold** — a geometric C/V reading. More structural and more complex; the detached upper segment is part of the mark.

Each SVG uses a 64 × 64 viewBox, has a transparent background, and inherits `currentColor` when embedded inline. An SVG loaded as an image defaults to black; set its color explicitly when preparing light artwork.

The inline comparison includes each mark at 16, 24, and 32 CSS pixels, a name lockup, a light reversal, and the existing double-C for reference. Clear space for these studies is at least one quarter of the mark width. Cut is the strongest option at small sizes.

The production website and its existing assets have not been changed. Select a direction before replacing the header, About illustration, scroll indicator, favicon, touch icons, and social artwork together.

## Round two: refine Cut

The user likes aspects of Cut but is not satisfied with the overall mark. This is partial interest, not approval to adopt it.

- **Soft cut** keeps Cut's substantial, compact form. The larger counter, gentler shoulders, and curved lower terminal reduce its aggressive parallel-chevron effect.
- **CV cut** keeps the original top cut and extends the lower arm into a rising V-like gesture. This explores a more specific relationship to the name, at the cost of a more angular silhouette.
- **Original Cut** remains in the comparison as the reference, rather than adding a third unrelated new direction.

Both new studies remain monochrome vectors. No production assets have been replaced.
