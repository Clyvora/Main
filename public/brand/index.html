A few simple rules

Give it room.

01

Keep the signature.

Use the supplied wordmark and its original proportions. Write the name as Clyvora in ordinary text.

02

Leave some space.

Allow half the lowercase letter height around the logo. Use the wordmark from 112 px wide; the icon suits smaller spaces.

03

Let it read clearly.

Choose a plain, contrasting background. Use Clyvora Display for short headings from 28 px, with system type for longer text.
